# Recommended Label Taxonomy

GitHub labels are not created automatically by this template — you (or your instructor) must add them in **Issues → Labels** on GitHub. The following taxonomy is recommended for MTEC 3501 project repositories.

## SRDMPA Phase Labels

- `speculate`
- `research`
- `design`
- `produce`
- `present-publish`
- `assess`

## Functional Labels

- `task`
- `experiment`
- `documentation`
- `feedback`
- `blocked`

Apply one phase label and, optionally, one or more functional labels to each issue. This keeps your Issues and Project boards organized by both project stage and work type.

## SRDMPA Organization

Your project moves iteratively through **Speculate → Research → Design → Make/Produce → Present/Publish → Assess** (SRDMPA). These stages are not a rigid waterfall — you will move back and forth between them repeatedly as your project develops.

### Speculate
Initial concepts, speculative writing, brainstorming, alternative possibilities, project scope, and aspirational versions of the project.

### Research
Precedent research, technical research, references, experiments, feasibility investigations, and research synthesis. Research sources should be maintained appropriately in Zotero when required by the course.

### Design
Design documentation, diagrams, specifications, system architecture, mediation pathways, planning, requirements, and design revisions.

### Make / Produce
Documentation associated with constructing, programming, composing, fabricating, testing, integrating, or otherwise realizing the project. Actual implementation files may live in `/prototype` or in additional project-specific directories you create.

### Present / Publish
Material concerned with communicating the project: presentations, demonstrations, documentation, portfolio preparation, and publication.

### Assess
Self-assessment, critique, feedback, jury responses, reflection, testing results, and decisions about subsequent iteration.

## Prototype

`/prototype` is intended for your functioning Proof of Concept and associated implementation material. Reorganize this directory when your project's technical requirements justify doing so.

## Assets

`/assets` is for supporting media such as diagrams, images, reference graphics, audio, video, data, or other project resources. Do not use this repository as indiscriminate bulk storage for extremely large binary media files — link out to external storage for large assets where appropriate.

## Deliverables

`/deliverables` is **not the complete project archive**. It contains only selected material intended for formal submission or presentation.

`/deliverables/final/` should ultimately contain your final MTEC 3501 submission package, including at minimum:

- final project proposal
- final presentation
- associated materials required to understand or evaluate those documents

Your complete working history remains elsewhere in the repository. Final course deliverables will subsequently be submitted or transferred to the main class repository according to course instructions.
